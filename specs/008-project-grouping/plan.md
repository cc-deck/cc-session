# Implementation Plan: Project Grouping View

**Branch**: `008-project-grouping` | **Date**: 2026-07-02 | **Spec**: [spec.md](spec.md)
**Input**: Feature specification from `specs/008-project-grouping/spec.md`

## Summary

Add a toggle-able project grouping view to cc-session's session list. Ctrl-T switches between the default flat chronological list and a grouped view where sessions are organized under collapsible project headers with chevron indicators. The grouping is purely a view-layer concern using a virtual row model: `DisplayItem` enum entries in the existing display list, with all filter/search logic unchanged.

## Implementation Approach

### Phase 1: Data Model (mod.rs)

1. Define `ProjectGroup` struct with `project_name`, `latest_timestamp`, `session_count`
2. Define `DisplayItem` enum with `Session(DisplayEntry)` and `Header(ProjectGroup)` variants
3. Add `grouped_mode: bool` and `expanded_projects: HashSet<String>` to `App`
4. Replace `display_entries: Vec<DisplayEntry>` with `display_items: Vec<DisplayItem>` on `App`
5. Update `rebuild_display_entries` (rename to `rebuild_display_items`) to handle both modes:
   - Flat mode: wrap each `DisplayEntry` in `DisplayItem::Session` (existing behavior)
   - Grouped mode: collect sessions by `project_name`, sort groups by latest timestamp, emit `Header` + `Session` items respecting expanded/collapsed state
6. Update all methods that access `display_entries` to use `display_items` instead: `display_session`, `enter_conversation`, `move_down`, `move_up`, `ensure_visible`, `poll_content_search`, `apply_filter`

### Phase 2: Input Handling (input.rs)

1. Add Ctrl-T handler in `handle_browsing`: toggle `app.grouped_mode`, clear `expanded_projects`, call `rebuild_display_items`
2. Modify Enter handler in `handle_browsing`: if selected item is a `DisplayItem::Header`, toggle expand/collapse instead of entering conversation
3. Ensure arrow key navigation works with headers (headers are navigable items, not skipped)

### Phase 3: Rendering (view.rs)

1. Modify `render_session_list` to handle `DisplayItem::Header` rows:
   - Render chevron (`▶`/`▼`) + project name + relative time
   - Use a distinct style (e.g., bold or different color) to distinguish from session rows
2. Indent session rows under expanded headers (prepend spaces)
3. Update border title to show project count when in grouped mode
4. Update scrollbar to reflect actual visible row count

### Phase 4: Tests

1. Test `rebuild_display_items` in grouped mode: correct grouping, ordering, collapse/expand
2. Test Ctrl-T toggle: flat to grouped and back
3. Test Enter on header: expand/collapse state changes
4. Test filter interaction: auto-expand matching groups, hide empty, clear restores collapsed
5. Test edge cases: single project, empty list, single session per project
